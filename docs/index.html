Built for Real Android to Mac Transfers

Most cross-platform sharing tools fail the moment you leave home Wi-Fi or try moving a 10 GB video. AirDrop P2P handles the radio, kernel, and network edge cases directly.

Bidirectional Android ↔ Mac

Send files from Android's Share Sheet or inside the app, and send back from macOS via drag-and-drop, Finder selection, clipboard, or Finder's AirDrop menu.

No Shared Router Required

Android opens a dedicated 5 GHz Band 4 Wi-Fi Direct group per session, so transfers work on trains, cafes, hotels, and studio sets with zero LAN access.

Stay Online on Mac

Android's embedded dual-protocol proxy (SOCKS5 and HTTP CONNECT on port 1080) routes Mac traffic over your phone's active internet or cellular connection while Wi-Fi Direct is up.

Pinned TLS + ECDH P-256

Ephemeral P-256 keys encrypt Wi-Fi credentials over BLE, TLS certificate SHA-256 fingerprints are pinned, and the default Ask First mode confirms before Mac joins a Wi-Fi Direct SSID.

No 35-Second Kernel Stalls

Periodic 2.0s UDP keepalives reset Android's Linux neighbor cache state so 10 GB+ HTTP streams do not freeze mid-transfer.

Files, Links, and Text Notes

Move batches of photos, 4K videos, PDFs, APKs, URLs, or quick notes. For full folder trees, select the contained files or send a zip archive.

Optional AI Summary Sidecars (Off by Default)

If you enable macos/claude_processor.py, received files on Mac can generate companion .claude.md notes using either on-device tools or Anthropic's Messages API.

Offline mode (no API key): Uses macOS Apple Vision OCR for images and an optional local Ollama server (llama3.2, mistral, qwen2.5, phi3) for summaries.

Privacy Guard: Before any file touches the cloud, filename rules and content regexes block .pem, .key, .env*, SSH keys, and exposed API tokens.

Build from source: Run cd macos && ./build.sh on macOS (Xcode CLT + Python 3.9+) and cd android && ./gradlew assembleDebug (JDK 17 + Android SDK 36). See the Architecture Specification and Security Policy for protocol details.

Frequently Asked Questions

Common setup, speed, proxy, and privacy questions for first-time users.

How do I send files from Android to Mac without USB or the same Wi-Fi network?

Install AirDrop P2P on both devices and open it. Android and Mac discover each other over Bluetooth Low Energy L2CAP, negotiate temporary 5 GHz Wi-Fi Direct credentials encrypted with ECDH P-256 and AES-256-GCM, and transfer directly over pinned TLS without a shared router or cable.

Does AirDrop P2P work from Mac to Android too?

Yes. Transfers work in both directions. From macOS you can drag files onto the menu bar icon or Send window, pick files by category, grab the current Finder selection or clipboard, compose a link or note, or send from Finder's AirDrop menu via the local AWDL proxy.

Is there a file size limit or cloud upload?

There is no file size limit and zero cloud upload. Transfers up to 8 GiB use standard POSIX CPIO headers, while larger files stream with 64-bit extended CPIO (070764) headers directly from file descriptors.

Will my Mac lose internet while connected to Wi-Fi Direct?

During 5 GHz Wi-Fi Direct transfers, Android can run an embedded SOCKS5 and HTTP CONNECT proxy on port 1080 (under Settings → Mac Internet Sharing Proxy) to share its active mobile data or upstream internet connection. macOS snapshots your previous proxy settings, applies the temporary proxy without sudo, and restores both your proxy config and home Wi-Fi once done.

How are transfers encrypted and protected against spoofing?

Wi-Fi Direct credentials travel inside an ephemeral ECDH P-256 + AES-256-GCM handshake over BLE (W2P2), and both sides exchange SHA-256 TLS certificate fingerprints to pin the HTTPS transfer. Under the default Ask First mode on macOS, joining a new Wi-Fi Direct group prompts once for confirmation; enabling Auto-Accept skips prompts for unattended transfers.

Can I send entire folders directly?

Not directly yet. Both Android and macOS stage single or multiple selected files, links, and text notes rather than directory trees. Select the files inside a folder or create a zip archive first when moving folders.

How do I avoid macOS Gatekeeper warnings when installing?

Install with AirDrop-P2P-v2.4.1.pkg, which installs into /Applications and runs xattr -cr during setup. If you downloaded the .dmg, run the bundled Gatekeeper helper script or run xattr -cr "/Applications/AirDrop P2P.app" in Terminal.

Does the AI summary feature send my private keys to the cloud?

No. AI ingestion is disabled by default. When enabled, the Privacy Guard blocks .pem, .key, .env*, SSH keys, and files containing API tokens from cloud upload, and local mode runs offline via Apple Vision OCR and Ollama.
